# Major Match 2026

Interactive guide for Year‑1 School of Data Science students choosing among:

- **CS** — Computer Science and Engineering  
- **DS** — Data Science and Big Data Technology  
- **STA** — Statistics  

## Flow

1. Shared School Package  
2. Placement reminder (“study well > hot major”)  
3. 8-question experience race (3 robot meters)  
4. Required-course comparison  
5. Graduation framework  
6. Summary  

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000/

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

1. Open [Settings → Pages](https://github.com/kwtsang101016/major-matching-2026/settings/pages)
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: **gh-pages** / **/ (root)** → Save

After the next successful Actions run (or a re-run), the site is at:

https://kwtsang101016.github.io/major-matching-2026/

## Stack

React + TypeScript + Vite
